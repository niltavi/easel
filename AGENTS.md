# Easel repository guidance

Before starting work, load the [Niltavi Project Skill](.agents/skills/niltavi-project/SKILL.md). Follow it to consult these sources in order:

1. Read the current [Niltavi Rules](https://github.com/niltavi/niltavi-rules#readme) and identify the rules that apply to the task.
2. Read the current [Niltavi Skills index](https://github.com/niltavi/niltavi-skills#readme) and load the skills relevant to the task.
3. Read the current [Niltavi UI documentation](https://github.com/niltavi/niltavi-ui#readme). For interface work, also read the relevant shared UI source and examples.

Complete these steps before proposing or implementing changes. The Niltavi Rules repository is the source of truth for shared rules. For Easel-specific context, read the [project README](README.md) and any guidance for the affected paths.
